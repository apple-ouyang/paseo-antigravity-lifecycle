Antigravity lifecycle integrates Antigravity CLI (`agy`) lifecycle hooks with Paseo, replaces generic `Other` tool cards in the timeline with structured cards, and adds a live multi-mode orchestration console panel for Swarm, Teamwork, Boost, `/goal`, Plan, Workflow, subagents, and background tasks.

`agy acp` reports custom orchestration tools (`swarm`, `post_message`, `read_board`, `swarm_wait`, `invoke_subagent`, `send_message`, `run_workflow`, `update_steps`, `enter_plan_mode`, `exit_plan_mode`, `schedule`, `manage_task`, `ask_question`) with `kind: "other"` and empty outputs, and can end a foreground turn while background work is still active. The plugin transforms these timeline items into readable cards (loading real message board posts on demand for `read_board` and `swarm_wait`), scans local session logs, swarm plans, message boards, and nested Teamwork subagent trees up to five levels deep, and exposes a split console panel via the composer pill, `/swarm-board`, `/agy-board`, and the command palette.

The hook script writes the hosting `agy` process ID from `PASEO_HOOK_AGENT_PID` into `process.json` on `PreInvocation` and `Stop`, and writes `hook-state.json` on `Stop` only so `ask_question` turns do not trigger false busy states. The server verifies OS process liveness before reporting active background work, so terminated or archived sessions clear immediately.

When enabled, the plugin writes `~/.paseo/agent-hooks/antigravity-hook.mjs` and registers it under a `paseo-status` key in `~/.gemini/config/hooks.json` for `PreInvocation`, `PostInvocation`, and `Stop`, leaving other entries untouched. Removing the plugin does not delete the script or the `paseo-status` entry; delete both to uninstall completely.

Requires Antigravity CLI (`agy`) installed on the daemon host. All session logs, swarm boards, and subagent records under `~/.gemini/antigravity-cli/brain` are read locally on the daemon host, with no external network requests.
